ITC C201 STUDENT PORTFOLIO WEBSITE

FILES
- index.html: website content and sections
- style.css: layout, colors, typography, and responsive design
- script.js: mobile navigation behavior
- assets/: syllabus, submitted activity PDFs, ERD image, and JPCS image evidence

PUBLISH / UPDATE ON GITHUB
1. Extract this ZIP file on your computer.
2. Open https://github.com/rylgh/ITC-C201-portfolio
3. Click Add file > Upload files.
4. Open the extracted folder on your computer.
5. Drag index.html, style.css, script.js, README.txt, and the assets folder into the upload area.
6. If GitHub asks about replacing files, allow it for the files with the same names. Keep the assets folder and its contents.
7. Scroll down and click Commit changes.
8. Wait for the Pages deployment to finish (green check in Actions).
9. Open https://rylgh.github.io/ITC-C201-portfolio/ and hard-refresh with Ctrl+Shift+R.

IMPORTANT
- The website lists Section 201I as the student's original section.
- Quiz and examination sections explain that individual records are unavailable; no scores have been invented.
- Only JPCS is listed as an organization membership.
- The website contains submitted work and the syllabus files provided. Please check the details before final submission.

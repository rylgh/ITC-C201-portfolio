ITC C201 Student Portfolio Website

Files:
- index.html: website content
- style.css: layout and visual design
- script.js: mobile navigation

Preview:
Open index.html in a web browser.

Publish:
Upload these files to a GitHub repository and enable GitHub Pages from
Settings > Pages. Choose Deploy from a branch, select main and / (root),
then save. GitHub will provide the public website URL.

Important:
This is a starter portfolio. Replace every "add" or "pending" note with
your actual work, evidence, and personal reflection before submission.
The official syllabus, completed activities, lab screenshots, quizzes,
projects, and verified examination results have not been supplied yet.

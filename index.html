02 / COURSE GUIDE

Course Syllabus

Official syllabus provided for ITC C201, First Semester, School Year 2026–2027.

COURSE DESCRIPTION

This course introduces database concepts, database design, creation, development, use, and management. It covers data dictionaries, normalization, data integrity, data modelling, simple tables, queries, reports, and forms, using Oracle Database basic SQL statements.

COURSE DETAILS

Credit units: 3 units
Contact hours: 2 lecture hours and 3 laboratory hours
Placement: Second Year, First Semester
Pre-requisite: MAT C604

Course learning outcomes

  1. Define database concepts, applications, database models, DBMS, and relational database theory.
  2. Apply data modelling and normalization in designing a database based on a business problem.
  3. Use basic SQL statements to create, manipulate, and query a database, and construct a working system using a relational database and a front-end language.

08 / LOOKING BACK

Learning Reflection

In Database Fundamentals, I learned how databases are planned, organized, created, and managed. The activities helped me understand how to make a conceptual model and an ERD before creating database tables. I also learned why normalization is important in organizing data and reducing repeated information.

Using Oracle APEX gave me practical experience with SQL statements. I worked with commands for creating and modifying tables, inserting and updating records, filtering information with conditions, and sorting and joining tables. Seeing the query results helped me understand how each SQL command changes or retrieves data.

Some topics require careful attention, especially database relationships, table changes, and writing SQL statements correctly. I worked through these tasks by following the activity instructions, checking the SQL code, and looking at the output after running the commands. These activities helped me become more familiar with database design and basic SQL.

I can use these skills in future IT projects because databases are important for storing and managing information in applications. This course gave me a foundation that I can continue improving as I study programming and system development.
